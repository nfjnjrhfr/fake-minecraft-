    # 等待建議結果…

    加到主畫面

    在 Safari 按下方的分享鍵 􀈂 → 加入主畫面。 之後點桌面圖示就會直接全螢幕打開這一頁並自動開始量測，不經過 Safari 網址列，也不需要登入。

    這個頁面不會做什麼

    網頁無法建立 VPN 連線。iOS 只允許有 NetworkExtension 權限的原生 App 接管系統流量，Safari 沒有這個 API——任何聲稱在瀏覽器裡幫你開 VPN 的網頁都做不到這件事。

    這一頁負責的是「選哪一國」：量測結果和設定檔產生。 真正的連線由 pyvpn 客戶端執行。
