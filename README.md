# 隨時鬧鐘 (Anytime Alarm)

純前端的網頁鬧鐘,單一 `index.html`,不用安裝、不用後端,直接用瀏覽器打開就能用。

## 使用方式

用瀏覽器打開 `index.html` 即可(或部署到任何靜態空間 / GitHub Pages)。
也已發佈為 Claude Artifact,可直接用網址開啟。

iPad / iPhone 建議:用 Safari 開啟後「加入主畫面」,再從主畫面啟動,背景執行最穩。

## 功能

**鬧鐘**
- 指定時間 + 自訂標籤(例如「起床」、「開會」)
- 快速鍵:1 / 5 / 10 / 30 分後、1 小時後,一鍵建立一次性鬧鐘
- 重複設定:選星期幾;不選就是只響一次(響完自動關閉)
- 三種鈴聲(嗶嗶 / 叮咚 / 警報),可先試聽
- 每個鬧鐘可獨立開關或刪除
- 鬧鐘存在瀏覽器 `localStorage`,重新整理不會消失

**倒數計時**
- 時 / 分 / 秒自由設定,支援開始、暫停續跑、重設
- 快速鍵:1 / 3 / 5 / 10 / 25 分鐘

**響鈴時**
- 全螢幕提示 + 循環鈴聲 + 手機震動(支援的裝置)
- 分頁標題會變成 ⏰,背景分頁也看得到
- 「貪睡」自動建立 5 分鐘後的鬧鐘
- 有授權時會一併發送瀏覽器通知

## 背景執行

網頁被切到背景或裝置鎖屏時,瀏覽器會凍結 JS 計時器。這個 App 用三層對抗:

1. **絕對時間排程** — 鬧鐘存的是絕對時間戳,不是靠倒數累加。頁面一回到前景
   (`visibilitychange` / `pageshow` / `focus`)就重新對時,補算休眠期間的鬧鐘。
   一小時內錯過的會立刻補響並標示延遲;超過一小時只顯示「錯過的鬧鐘」提示,不強行吵人。
2. **Web Audio 預先排程** — 開啟背景執行後,會把下一次鈴聲(30 分鐘內)直接排到
   `AudioContext` 的音訊硬體時鐘上。音訊執行緒不受 JS 節流影響,所以 JS 被凍結時鈴聲照響。
3. **無聲音軌 + Wake Lock** — 播放一段振幅 1 LSB(聽不見)的循環 WAV,讓 iOS 維持這頁的
   音訊工作階段,鎖屏 / 切換 App 時頁面繼續跑;同時嘗試取得 Screen Wake Lock。

畫面上的狀態列會即時顯示這三層各自的狀態。

## 注意事項

- 把瀏覽器**整個從多工列滑掉(強制結束)**,系統會終止所有網頁,那時不會響 —
  這是網頁的硬限制,沒有任何純前端方案能繞過。回到頁面時會補算補響。
- 瀏覽器的自動播放限制:背景執行需要你先點一次「開啟背景執行」才能啟用。
- Screen Wake Lock 在跨來源 iframe 中需要 `allow="screen-wake-lock"`,取不到時會靜默降級,
  狀態列不會顯示「螢幕保持開啟」。
- 資料存在瀏覽器 `localStorage`;作為 Artifact 執行時,若 `db` capability 可用會同時
  同步到伺服器(跨裝置共用),取不到時自動退回純本機。
