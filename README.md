# 數學通道 · 嗶哩嗶哩觀看通道

一個純前端的小網頁，把離線緩存裡那幾個數學片單集中成一個「通道」，
直接用 B 站官方播放器內嵌播放，帶分 P 清單與觀看進度。

![四個預設片單](https://img.shields.io/badge/預設片單-4-fb7299)

## 內建片單

BV 號、每一集的標題與長度都已經寫進 `assets/data.js`，開啟網頁就能直接播，不用自己綁定。

| 数学 · 四维之眼 | 4P | — | **未綁定**，貼一次連結即可 |
| 草履虫教学 | 3 集 | 合集，首集 `BV1RHVD6TE8y` | 已綁定 |
| 【加数】高中一课通 | 31 集 | 合集，首集 `BV1tW87zREjC` | 已綁定 |

「四维之眼」在 B 站搜不到能確定是同一支的影片（截圖裡那張卡片的標題只是緩存資料夾名「数学」），
所以留白沒亂綁。點進去按「貼上連結綁定」貼一次就好。

## 怎麼用

直接用瀏覽器打開 `index.html`（雙擊即可，不需要伺服器、不需要安裝任何東西），
點片單就開始播。想放到網路上就把整個資料夾丟上 GitHub Pages / 任何靜態空間。

觀看進度、自己新增的片單、播放設定都存在瀏覽器本機（localStorage），不會上傳。

## 連續播放

右上角的「▶ 連續播放」預設是開的，配合自動播放：一集播完就自動跳下一集，直到片單最後一集。

因為播放器是 B 站官方的跨網域 iframe，網頁沒辦法直接收到「影片播完了」這個事件，
所以連續播放是**用每一集的實際長度倒數計時**（片單裡的 `dur` 欄位，加 6 秒緩衝）。
播放器下方會顯示還剩多久，中途暫停或拖進度條時可以用：

- **暫停倒數 / 繼續倒數** — 你去接個電話時按一下
- **＋30 秒** — 倒數跑太快就補時間
- **關閉** — 這次不要自動跳

自動跳走前會把上一集標記成已看。片單最後一集不會倒數。

### 讓綁定變成預設值

在頁尾按「匯出片單」會把目前的片單 JSON 複製到剪貼簿，
貼進 `assets/data.js` 的 `collections` 之後，換一台裝置或清掉瀏覽器資料也還在。
`assets/data.js` 最上面有每個欄位的說明。

## 功能

- 首頁卡片牆：封面、分 P 數、已看進度條、「繼續觀看」
- 播放頁：官方 iframe 播放器、分 P 清單、上一 P / 下一 P（← → 方向鍵也可以）、標記已看、在 B 站開啟
- 搜尋片單與分 P 標題
- 連續播放：倒數結束自動跳下一集，可暫停 / 補時 / 關閉
- 設定：彈幕開關、自動播放、寬屏、連續播放
- 匯出 / 匯入片單 JSON、一鍵重置本機資料
- 深色 / 淺色跟隨系統，手機版面自適應

## 已知限制

- 連續播放是倒數計時，不是真的偵測「播完了」。你暫停影片、拖進度條、或影片前面卡了廣告，
  倒數就會跟畫面對不上，用「暫停倒數 / ＋30 秒」校正。
- 瀏覽器的自動播放限制：有些瀏覽器要你先在頁面上點過一下才允許自動播放，
  第一集可能需要手動按一次播放鍵。
- 少數影片（番劇、付費課程、UP 主關閉了外站播放）不允許站外內嵌，
  這種情況播放器會顯示錯誤，用「在 B 站開啟」看即可。
- 大會員限定內容、需要登入的內容一樣受 B 站規則限制，這個頁面不會、也不能繞過。
