# 開玉 — 上山採玉模擬

一個純前端（HTML + CSS + 原生 JS，無任何相依套件）的翡翠開採經營遊戲。
你是一支採玉隊的頭家：帶工人上山、付礦權、開坑挖料、打燈相玉、一刀切開見真章，
再把料賣給玉商或送公盤。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可。（或 `npx http-server .` 後開 `localhost:8080`）
進度自動存在瀏覽器 localStorage，頂欄可手動存檔／重新開始。

## 一天的流程

1. **營地** — 編隊、檢查裝備清單、挑場口。付礦權日費才能上山。
2. **礦場** — 在岩壁格網上用工具挖掘。只能從洞口或已開挖處往裡推進。
3. **收工** — 依載重上限挑要扛下山的料，其餘留在山上（下次來還在）。
4. **工房** — 打燈看種、放大鏡看裂、磨機開窗看色，決定賣原石還是切開。
5. **市場** — 賣給三位輪替的玉商，或每 7 天一次的公盤暗標。
6. **結束這一天** — 發工資、吃糧、療傷、天氣與玉價指數變動。

## 六個場口

| 場口 | 礦權/天 | 特性 |
|---|---|---|
| 會卡 | $4,000 | 入門場口，皮厚肉粗，量大價低 |
| 大馬坎 | $12,000 | 黃霧紅霧，易出黃翡紅翡，水坑多 |
| 木那 | $60,000 | 種老色陽、點狀棉，山路難行 |
| 莫西沙 | $130,000 | 高透明度第一場口，圍岩極硬、塊頭小 |
| 後江 | $70,000 | 小塊高色，水位高，沒抽水機下不了坑 |
| 帕敢老坑 | $260,000 | 大料高綠，坑深塌方多，賭的是命也是錢 |

每個場口的種水／色／裂偏向、圍岩硬度、水位、危險度、路況都不同。

## 所有設備都能實際操作

**採掘工具**（礦場工具列，快捷鍵 1~8）— 每把的作用範圍、威力、體力、傷玉率都不同：

| 工具 | 範圍 | 特點 |
|---|---|---|
| 鐵鏟 | 單格 | 挖土快，敲石頭沒用 |
| 十字鎬 | 單格 | 萬用，土石通吃 |
| 大鐵鎚 | 直三格 | 破圍岩猛，砸到玉必裂 |
| 鑿子＋手鎚 | 單格 | 慢，但幾乎不傷玉 — **取料就靠它** |
| 撬棍 | 橫三格 | 沿縫撬鬆圍岩，傷玉極低 |
| 風鎬 | 十字 | 需空壓機供風＋柴油，震裂率 50% |
| 挖土機 | 3×3 | 需機械師親自操作，剝離表土無敵，傷玉 72% |
| 爆破器材組 | 半徑 2 | 需爆破手＋炸藥，開得最快，傷玉 85%、最容易出人命 |

**支援** 頭燈／探照燈（照明半徑，決定你看得見多少岩層）、發電機、空壓機、抽水機（水線以下的效率）、坑木支撐（塌方風險 -18%/組）
**安全** 安全帽、安全繩、全身吊帶、急救箱 — 依「每人一件」的覆蓋率生效，影響事故率與傷停天數
**運輸** 背簍／手推車／騾隊／小貨卡／十輪大卡 — 決定每天扛得下山幾公斤，路況不夠好的場口大車開不進去
**工房** 強光手電筒（揭示種）、十倍放大鏡（揭示裂與棉）、手持磨機（開窗揭示色）、切石機（全揭示）、拋光機（+30%）、電子秤（少被殺價 8%）
**營地** 工寮帳篷、爐具、無線電

設備會磨損，耐久歸零就報廢；維修比重買便宜。機具吃柴油、頭燈吃電池、磨機吃砂輪片、切石機吃切割片。

## 賭石的核心規則

每顆原石的**種、色、裂、棉**在挖出來時就已決定，但你看不到。

- 揭示越多資訊 → 你的估價越準，**但玉商也看得到**，賭性溢價就沒了
- 完全不動的原石，玉商會用自己的眼力估價再打賭性折扣，運氣好可以賣超過實價
- 一刀切開 = 全揭示，按實價交易。漲或垮，就這一刀
- **相玉師**的眼力決定你看到的估價區間有多窄、開窗切石有多容易失手

價值 = 種的基價 × 色的倍率 × (1 − 0.72×裂) × (1 − 0.35×棉) × 重量 × 大料加成。
玻璃種帝王綠的大料是萬中選一，磚頭料再大也不值錢。

## 工人

五種角色：礦工、爆破手、機械師、相玉師、背工。各有採礦／爆破／機械／相玉技能值。
挖土機與爆破必須由**當下選定的那個人**親自操作，技能不到就用不了。
工人有體力、士氣、傷勢；欠薪、斷糧、事故會讓士氣崩盤，太低會直接走人。
