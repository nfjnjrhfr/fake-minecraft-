# 方塊對戰 Block Brawl

像素方塊風格的對戰遊戲，有兩個版本：

| 版本 | 位置 | 說明 |
| --- | --- | --- |
| **網頁版** | 這個資料夾 | 2D，純 HTML + Canvas + JS，開啟即玩。**手機有內建虛擬搖桿**，不用鍵盤 |
| **Roblox 版** | [`roblox/`](roblox/) | 3D 線上多人版，Luau 腳本貼進 Roblox Studio 即可 |

---

# 網頁版

純 HTML + Canvas + JavaScript，沒有任何相依套件與建置流程。

## 開始玩

直接用瀏覽器開啟 `index.html` 就能玩（雙擊檔案即可，不需要架伺服器）。

手機請把螢幕轉成**橫向**，畫面會自動全螢幕並顯示虛擬搖桿。

或用任意靜態伺服器：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 遊戲模式

- **單人對戰電腦**：跟有 AI 的方塊人對打。
- **雙人同機對戰**：兩個人共用一個鍵盤（或同一個平板，左右各一組搖桿）。

先贏 **3 回合** 者取得勝利，每回合限時 90 秒；時間到時血量高的一方勝出。

## 操作方式：手機 / 平板（虛擬搖桿）

不需要外接鍵盤，全部都在螢幕上：

| 動作 | 操作 |
| --- | --- |
| 左右移動 | 左下角**虛擬搖桿**往左 / 右推 |
| 跳躍 | 搖桿往**上**推，或按「跳」 |
| 快速下落 | 搖桿往**下**推 |
| 揮劍 | 按「劍」（可**長按**連續揮） |
| 丟雪球 | 按「雪」（可**長按**連射） |
| 放方塊 | 按「磚」 |
| 暫停 | 畫面上方的 ❚❚ |

選單、暫停、再玩一場都可以直接用點的。雙人同機時，兩組搖桿分別在左下角與右下角。

## 操作方式：鍵盤

| 動作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左右移動 | `A` / `D` | `←` / `→` |
| 跳躍（按著跳更高） | `W` | `↑` |
| 快速下落 | `S` | `↓` |
| 揮劍 | `F` | `K` |
| 丟雪球 | `G` | `L` |
| 放方塊 | `R` | `;` |

其他：`↑` `↓` 選單移動、`Enter` 確定 / 再玩一場、`P` 暫停、`M` 靜音、`Esc` 回主選單。

## 玩法重點

- **揮劍** 近距離造成 13 點傷害並把對手擊退；**沒打到人時會挖掉前方的方塊**，可以拿來開路或拆掉對方的牆（挖到的方塊有機會回收）。
- **雪球** 造成 10 點傷害，有拋物線，會被地形擋下；彈藥會隨時間慢慢回補。
- **放方塊** 可以擋雪球、補地板、或架高逃跑，數量同樣會慢慢回補。
- **掉出場外**扣 35 點血並送回出生點，血扣光才算輸掉該回合；地圖中間跟兩側都有坑，注意腳下。
- 場上會定時掉落道具：❤️ 補血 30、雪球 +5、方塊 +5、金蘋果（8 秒內受到的傷害減半）。
- 每回合都會重新生成地形，而且**左右完全對稱**，兩邊條件一樣公平。

## 檔案結構

```
index.html   頁面外殼
style.css    版面與縮放（畫面自動等比例填滿視窗、手機橫向全螢幕）
game.js      全部的遊戲邏輯：地形生成、物理碰撞、戰鬥、AI、觸控、繪圖、音效
roblox/      Roblox 版（Luau），見 roblox/README.md
```

`game.js` 內部大致分成：常數 → 輸入 → 觸控 → 音效 → 地形生成 → 實體與物理 → 戰鬥 → AI → 更新迴圈 → 繪圖，
以固定 60 FPS 的邏輯步長運作，畫面用 `requestAnimationFrame` 更新。
虛擬搖桿與按鈕直接畫在 canvas 上、也在 canvas 座標系裡做碰撞判定，所以縮放到任何螢幕都對得準。

# Roblox 版

完整說明在 [`roblox/README.md`](roblox/README.md)：怎麼貼進 Roblox Studio（不用裝任何工具）、
或用 Rojo 同步、操作方式與規則。

手機上**移動搖桿是 Roblox 內建的**，這份程式另外加了「劍 / 雪 / 磚」三顆觸控按鈕。
所有冷卻、彈藥數與傷害判定都在伺服器端計算。

```
roblox/default.project.json                Rojo 專案
roblox/src/ReplicatedStorage/GameConfig.luau           共用參數 + 場地藍圖（純資料）
roblox/src/ServerScriptService/BattleServer.server.luau 場地、回合、戰鬥判定
roblox/src/StarterPlayer/.../BattleClient.client.luau   HUD 與觸控按鈕
roblox/tests/arena_test.luau               場地藍圖的對稱性測試（用 luau CLI 跑）
```
