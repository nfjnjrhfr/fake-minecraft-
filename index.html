Synthesis Camp Games

Playable versions of the collaborative strategy games run at Synthesis — the programme that started as a class at Ad Astra, the school Elon Musk set up on the SpaceX campus.

The originals are multiplayer, moderated, and deliberately taught without rules: children are dropped into the simulation mid-stream and have to work out what is going on. These are single-player reconstructions of the same mechanics — shifting scoring, common-pool resources, sealed bids, an opponent that is a system rather than a person. Every one runs in the browser with no build step and no network.

Original game concepts belong to Synthesis. These are independent implementations written from published descriptions of how each game plays — no Synthesis code, art or content is used. Open index.html in any browser, or serve the folder statically.
